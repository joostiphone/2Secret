# Winkelvermelding (Nederlands)

**Naam:** 2Secret

**Samenvatting (maximaal 132 tekens):**
Gratis, open-source wachtwoordmanager: vul logins, eenmalige codes en passkeys in vanuit je end-to-end versleutelde kluis.

**Beschrijving:**

2Secret is een gratis, open-source wachtwoordmanager. Je kluis wordt op je
eigen apparaten versleuteld met je hoofdwachtwoord en een Secret Key; de
server (de onze of je eigen) ziet nooit een wachtwoord, een website of zelfs
maar een titel.

De extensie brengt je kluis naar de browser:

- Suggesties voor de website waar je bent, en met één klik gebruikersnaam,
  wachtwoord en eenmalige code invullen. Er wordt niets ingevuld zonder jouw
  klik, en alleen op pagina's die bij de website van het item horen.
- Passkeys: bewaar ze in je kluis en log ermee in vanuit elke browser.
- Wachtwoordgenerator, favorieten, tags, zoeken.
- Met de 2Secret-app voor de computer: een AI-agent die in je browser werkt
  kan 2Secret vragen je in te loggen. Jij staat het toe in de app, 2Secret
  vult de inlogpagina in, en de agent ziet het wachtwoord nooit.

Werkt samen met de 2Secret-apps voor macOS, Windows, Linux, iPhone, iPad en
Android en met de 2Secret-opdrachtregel. Synchroniseer via 2secret.app of je
eigen server; de code staat op GitHub.
