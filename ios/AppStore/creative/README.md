# App Store creative assets

The product page header and search results images, per language, in the
sizes from App Store Connect Help, *Creative assets specifications*:

| File | Placement | Size |
|---|---|---|
| `*/header.png` | Product page header (21:9) | 3840 × 1646 |
| `*/search-results.png` | Search results (3:2) | 3840 × 2560 |

Opaque PNG (no alpha channel). The screens are the App Store screenshots in
`../design/screens`. What matters stays in the middle of each image, as Apple
asks, because the header is cropped on narrower screens.

Upload them in App Store Connect under *Asset Library*, submit them for
review, then choose them per language under *Product Page Information →
Header and Search Results*. No prices or offers in these images: App Store
creative assets may not show them.
